look-what-i-can-do 🤸

Your README,
as an animated hero.

One image URL types your run command and plays its output, right at the top of your README. No install. No build. No commit.

Try it on your repo

Any public GitHub repo. What you see is what your README will show.

Paste a repo or its GitHub link.


          
        

      

    

  


  

    
How it works

    
It reads the README GitHub already shows. Nothing runs from your repo.

    

      

        
Show a real run

        
A console block with a $ command and its output. Add hero to pick which one.

        
```console hero
$ npx your-tool
✓ all 9 checks passed
```

      

      

        
Paste one image

        
At the top of the README, with your owner and repo.

        
<img src="https://lookwhaticando.dev/
  owner/repo.svg" width="800">

      

      

        
Push

        
That's it. Edit the README later and the hero follows within about 7 minutes.

      

    

  


  

    

      
A few KB of SVG
Sharp at any size, animated without a GIF's weight or blur.

      
No cap
It shows your README's own text, as written. Nothing added, nothing invented.

      
Private stays private
Only public README files are read. Private repos are never served.

      
Never a broken image
If something's off, the image itself says what and how to fix it.

      
Real colors, or a GIF
npx look-what-i-can-do --live runs the command for real. --gif for X and LinkedIn.

      
Monorepos and branches
?path= picks another README, ?ref= a branch or tag, ?highlight= a line.
